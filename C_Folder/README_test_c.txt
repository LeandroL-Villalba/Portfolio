---test_C (Programa de Gestion de Empleados)

Este programa permite al usuario cargar una serie de registros determinada (por medio de un .txt con las posiciones) segun el sector elegido desde un archivo ordenado por ID. Una vez cargado el sector, el usuario puede operar sobre los registros tras optar entre un metodo automatico (por ID) o manual (pasando registro por registro con visualizacion del contenido de por medio) de busqueda y, una vez seleccionada la entrada deseada, realizar la operacion correspondiente.
Actualmente, las operaciones disponibles son:
						*Modificar sueldo (Aumento/Reduccion)
						*Ingresar empleado
						*Desvincular empleado

La cantidad de operaciones disponibles esta abierta a expansion.

El usuario tiene la capacidad de realizar multiples busquedas y operaciones sobre el mismo sector. 

Una vez finalizada la sesion, se actualizan los registros en el archivo original.
